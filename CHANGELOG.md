# Changelog

## 1.2.0 - 2026-06-23

### Scientific Visualization

- Все карты и диаграммы переведены на единый стиль публикационного качества:
  `DejaVu Sans`, белый фон, крупная типографика и сохранение с `dpi=300` и
  `bbox_inches="tight"`.
- Для непрерывного NDVI используется насыщенная палитра `RdYlGn`; для Delta
  NDVI применяется `RdYlGn_r` с обязательным центрированием шкалы в нуле через
  `TwoSlopeNorm`.
- Карты классов используют фиксированные профессиональные цвета, одинаковые
  легенды, тонкую черную границу района, компактную северную стрелку и
  черно-белую масштабную линейку.
- Цветовые шкалы сделаны уже и ближе к картам; подписи CRS и источника данных
  унифицированы.
- Столбчатые диаграммы получили ColorBrewer-палитру, подписи значений,
  горизонтальную сетку и упрощенные рамки.
- Повторяющийся код оформления вынесен в общие функции
  `modules/visualization.py`; математические алгоритмы проекта не изменялись.
- Убраны фиксированные границы colorbar `[-1; 1]`: серия NDVI использует общий
  устойчивый диапазон 5-99 процентилей валидных значений, Delta NDVI использует
  автоматический диапазон 2-98 процентилей с центром `0`.
- Непрерывный NDVI переведен на бежево-зеленую палитру без красных оттенков;
  Delta NDVI использует красно-бело-зеленую дивергентную палитру.
- Легенды, северная стрелка и блок CRS/источника получили внутренние отступы;
  colorbar сокращен и ограничен шестью основными делениями.
- Цвета столбцов синхронизированы с картами классов, над столбцами выводятся
  площадь в гектарах и процент общей площади.

### Scenario Markov Forecast

- Линейная экстраполяция в `forecast_ndvi_linear()` заменена сценарной
  моделью цепей Маркова, автоматической кластеризации динамики и
  пространственной карты потенциала изменений; публичный интерфейс функции
  сохранен.
- Матрица переходов `transition_matrix.xlsx` нормализуется до вероятностей
  переходов классов NDVI; при отсутствии корректной таблицы счетчики переходов
  рассчитываются по классифицированным растрами автоматически.
- Все полигоны `change_polygons.gpkg` участвуют в прогнозе. Для каждого
  полигона рассчитывается `forecast_weight` по площади, модулю среднего Delta
  NDVI, числу соседних полигонов, компактности и контекстному Delta NDVI.
- `create_spatial_influence()` строит поверхность потенциала изменений:
  влияние полигона затухает с расстоянием, при перекрытии используется
  максимум влияния, а итоговая поверхность ограничивается общей валидной
  областью.
- Выбор пикселей для деградации учитывает влияние полигонов, оставшуюся
  емкость к изменению, соседнюю потерю NDVI и локальную вариативность в окне
  5 x 5; сильно разрушенные низкорастительные пиксели исключаются из
  дальнейшей деградации.
- Добавлен отдельный проход мягкого озеленения стабильной городской территории:
  низкие NDVI рядом с зелеными зонами получают небольшой прирост, имитирующий
  газоны, кустарники и молодые деревья.
- В журнал добавлены параметры кластеризации, статистика кластеров, веса
  полигонов, сценарии, матрица вероятностей, квоты Markov, число выбранных и
  реально измененных пикселей, площадь влияния и средняя потеря NDVI.

## 1.1.0 - 2026-06-17

### Critical Fixes

- Добавлена корректная обработка готовых NDVI: Float32 NDVI и Int16 x 10000
  распознаются автоматически, неоднозначный формат останавливает обработку.
- Переработано чтение rasterio mask, NoData, scale и offset.
- Добавлена запись внутренней маски NoData в итоговые GeoTIFF.
- Добавлена общая маска валидных пикселей `valid2015 AND valid2025`; по ней
  выполняются Delta NDVI, прогноз, статистика, классификация и переходы.
- Усилена проверка входных данных: CRS, разрешение, affine transform,
  scale/offset, диапазон значений, число каналов, пересечение с границей.

### GIS Methodology

- Alignment больше не выбирает reference raster автоматически.
- Целевая сетка задается явно: CRS, разрешение, origin, affine transform и
  extent от границы исследования.
- Площадь классов считается по валидным пикселям общей сетки.
- Метод пиксельной аппроксимации границы задокументирован в README и отчете.
- Пороги NDVI, Delta NDVI, прогноза и выделения изменений вынесены в `config.py`.

### Inputs

- Убрана жесткая привязка к конкретному имени Shapefile.
- Добавлен автоматический поиск ровно одного векторного файла границы в
  форматах `.gpkg`, `.shp`, `.geojson`.
- Добавлен fallback для двух файлов `ndvi*.tif`, если стандартные имена
  `ndvi2015.tif` и `ndvi2025.tif` не используются.

### Outputs

- Добавлен `transition_matrix.xlsx` с матрицей переходов классов NDVI.
- Добавлены `delta_ndvi.tif`, `delta_class.tif` и соответствующие PNG.
- Добавлены `change_polygons.gpkg` и `largest_changes.xlsx` для крупнейших
  участков деградации и улучшения.
- Word-отчет переведен на `python-docx`; отчет содержит параметры обработки,
  версии библиотек, таблицы, статистику, рисунки и список созданных файлов.
- PNG-карты дополнены координатной сеткой, границей района, CRS, источником
  данных, масштабом и северной стрелкой.

### Verification

- Добавлен `verify_pipeline.py`.
- Верификатор проверяет входные данные, CRS, сетку, диапазоны NDVI/Delta,
  NoData, статистику, Excel, Word, GeoPackage, PNG, матрицу переходов и
  полигоны изменений.
- `requirements.txt` закреплен конкретными версиями библиотек.
